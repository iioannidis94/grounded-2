# Grounded 2 - Progress Tracker & Database

Ένα static web application σχεδιασμένο για να παρακολουθείτε την πρόοδό σας στο παιχνίδι Grounded 2 (περιοχές, όπλα, πανοπλίες, Omni Tools). Σχεδιασμένο με HTML, CSS και Vanilla JavaScript, βελτιστοποιημένο για φιλοξενία στο GitHub Pages.

## 📌 Χαρακτηριστικά
* **Τοπική Αποθήκευση (Local Storage):** Η πρόοδος (τι έχετε τικάρει) αποθηκεύεται τοπικά στον browser. Δεν χρειάζεται βάση δεδομένων, δεν χάνονται τα δεδομένα με το refresh.
* **Ανεξάρτητα Data Files:** Όλα τα δεδομένα του παιχνιδιού (ονόματα, εικόνες, στατιστικά) είναι οργανωμένα σε ξεχωριστά `.js` αρχεία μέσα στον φάκελο `data/`.
* **Υποστήριξη Εικόνων (Sprites):** Οπτική αναπαράσταση κάθε αντικειμένου μέσω του φακέλου `assets/sprites/`.

## 📂 Αρχιτεκτονική Έργου (Folder Structure)
Η δομή του κώδικα έχει σχεδιαστεί για να είναι επεκτάσιμη:
* `data/` -> Περιέχει αρχεία JavaScript (ES6 Modules) που δρουν ως βάση δεδομένων. π.χ., `weapons.js`.
* `js/main.js` -> Αναλαμβάνει να ενώσει τα δεδομένα του `data/` με την πρόοδο που είναι αποθηκευμένη στο `localStorage` και να τα εμφανίσει στο DOM.
* `assets/sprites/` -> Εδώ αποθηκεύονται όλες οι εικόνες, κατηγοριοποιημένες σε υποφακέλους (`/weapons`, `/armor`, κλπ).

## 🛠️ Πώς να προσθέσετε νέα αντικείμενα
Για να προσθέσετε ένα νέο όπλο, δεν χρειάζεται να πειράξετε το HTML ή τη βασική λογική!
1. Τοποθετήστε την εικόνα του όπλου (π.χ. `new_sword.png`) στον φάκελο `assets/sprites/weapons/`.
2. Ανοίξτε το αρχείο `data/weapons.js`.
3. Προσθέστε ένα νέο αντικείμενο (object) στο array:
   ```javascript
   { 
       id: 'w_new_sword', 
       name: 'The Epic Sword', 
       sprite: 'assets/sprites/weapons/new_sword.png',
       description: 'Περιγραφή του όπλου εδώ.'
   }
